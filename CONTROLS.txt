DEADLY PREMONITION - КЕРУВАННЯ КЛАВІАТУРОЮ ТА МИШЕЮ
====================================================

Біндинги повторюють офіційну розкладку Director's Cut PC порту,
1:1 із внутрішнього меню "CONTROLLER SETTING" гри. Геймпад (Xbox /
DualSense) теж працює паралельно — використовуй що зручніше.

РУХ І КАМЕРА
------------
  W A S D            Йти / Бігти (York завжди бігом)
  Миша               Огляд камерою (правий стік)
  Колесико ↑/↓       Змінити зброю (D-pad ↑/↓)

ВЗАЄМОДІЯ / ОСНОВНІ ДІЇ
-----------------------
  E                  Взаємодіяти / Підняти предмет / Підтвердити (A)
  R                  Відмінити / Перезарядити / Закрити меню (B)
  C                  Спостерігати (L-stick press)
  F                  Увімкнути / Вимкнути ліхтарик (Y)
  Shift              Особливі рухи в кат-сценах (X)

БІЙ / ЗБРОЯ
-----------
  Space              Тримай: дістати зброю / прицілитися (RT)
  Space + ЛКМ        У режимі зі зброєю: вистрілити / вдарити (A)
  Control            Тримай: затримати дихання / автоприціл (LT)
  Z                  Strafe вліво (LB)
  X                  Strafe вправо (RB)

МЕНЮ / СПЕЦІАЛЬНІ КНОПКИ
-------------------------
  Enter              Меню паузи (Start)
  M                  Меню навігації / Мапа (Back)
  F4                 Налаштування емулятора (поза грою)
  ~ (тильда)         Консоль емулятора (для debug, не потрібна)

ДЛЯ ВИХОДУ З ГРИ
----------------
  Enter → "Quit Game" у меню паузи
  або просто закрий вікно (Alt+F4 на ноутбуках)

ЯК ЗМІНИТИ БІНДИНГ
-------------------
1. Натисни **F4** у грі — відкриється меню налаштувань
2. Зліва вибери Input → Keybinds → Controller
3. Клацни на потрібну дію та введи нову клавішу
4. Внизу натисни "Save to config" — збережеться у deadlyprem.toml
5. Зміни активуються відразу

Або відредагуй `deadlyprem.toml` поруч з `deadlyprem.exe` напряму.
Валідні назви клавіш: A-Z, 0-9, F1-F12, Space, Return (Enter),
Tab, Escape, Backspace, Shift, Control, Alt, PageUp, PageDown,
Home, End, Insert, Delete, стрілки (Up/Down/Left/Right), LMB, RMB,
MMB, WheelUp, WheelDown.

ЧАСТО СТАВЛЕНІ ПИТАННЯ
----------------------
**Чутливість миші занадто/недостатньо швидка**
F4 → Input → знайди `mnk_sensitivity` → змінити (0.1 повільно, 0.5 швидко).

**Камера не робить повний оберт**
Це нормально для миши-стик емуляції. Робимо короткий швидкий флік
мишею — стік "інерційно" продовжить крутитися ще ~0.25с. Не треба
тягнути мишу безперервно.

**Хочу повернутися до геймпада**
F4 → Input → вимкни `mnk_mode`. Підключи будь-який Xbox / DualSense /
сумісний контролер — працює одразу.

**Гра в вікні замість fullscreen / не той розмір**
Відкрий `deadlyprem.toml`, знайди `fullscreen = true` (або зміни) і
`window_width` / `window_height`. Перезапусти гру.

**Не можу клікати по UI в F4 (курсор не видно)**
Виправлено у цьому білді. Якщо все ще трапляється — повідом.
