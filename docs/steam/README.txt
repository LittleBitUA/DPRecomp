Deadly Premonition Recompilation - Steam artwork
https://github.com/LittleBitUA/DPRecomp

Custom artwork for the game added to Steam as a non-Steam shortcut, by
the <<Little Bit>> team.

  grid.png   600 x 900    vertical capsule (library grid, "portrait")
  hero.png   1920 x 620   hero banner (the wide image at the top of the game page)
  logo.png   1280 x 720   logo, transparent background (drawn over the hero)

HOW TO ADD THE GAME TO STEAM
  1. Steam -> Games -> Add a Non-Steam Game to My Library -> Browse...
     pick PlayDeadlyPremonition.exe from your DPRecomp folder.
  2. In the Library, right-click the new entry -> Properties: name it
     "Deadly Premonition Recompilation". If you get a black screen or a tinted
     quarter frame when starting through Steam, set Steam Overlay to "off" in
     the launcher (Advanced tab).

HOW TO APPLY THE ARTWORK (Steam client, no extra tools)
  - Vertical capsule: in the Library grid, right-click the game -> Manage ->
    Set custom artwork -> grid.png
  - Hero and logo: open the game's page, right-click the big banner at the top
    -> Set custom background -> hero.png; right-click the logo area ->
    Set custom logo -> logo.png (you can drag the logo position afterwards).

OR BY FILE (all three at once)
  Copy the files into  <Steam>\userdata\<your account id>\config\grid\  renamed
  to  <appid>p.png  (grid),  <appid>_hero.png  and  <appid>_logo.png,  where
  <appid> is the shortcut's id (SteamGridDB Manager and similar tools do this
  for you), then restart Steam.

example.jpg shows the result: the game page in Steam with the hero and the
logo applied (the logo can be dragged to the centre, as in the example).
