Host texture replacements (see rexglue-sdk src/graphics/pipeline/texture/replacement.cpp).

<hash>.png          - replaces the guest texture with this RGBA PNG (any size, mips generated at load)
<hash>.overlay.png  - composited over the decoded guest texture where the PNG alpha > 0

The hash is XXH64 of the guest base level (seeded with width/height/format); set
texture_dump = true in deadlyprem.toml to write every loaded texture to textures/dump/<hash>_<w>x<h>_<fmt>.png.
