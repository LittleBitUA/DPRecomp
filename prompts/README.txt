Button prompt icon sets used by the launcher (Controls -> Button Prompts).

ps_fullsolid, ps_solid, ps_outline: "PS5 Button Icons and Controls" by Zacksly,
licensed under CC BY 3.0 - https://zacksly.itch.io (resized; otherwise unmodified).
See LICENSE-zacksly.txt.

Each set is a folder with these PNG names (transparent background):
Cross, Circle, Square, Triangle, L1, R1, L2, R2, Left Stick Click, Right Stick Click,
Left Stick All, Right Stick, Left Stick Left-Right, Right Stick Left-Right, Right Stick Up-Down, Options, Create.
Drop another folder with the same file names next to these to add your own set.
